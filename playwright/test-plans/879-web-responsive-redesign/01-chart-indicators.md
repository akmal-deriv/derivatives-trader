# Suite 1 — Expandable Chart with Inline Indicator Management

> **Story:** Expand the chart and manage indicators (hide, show, edit, delete) directly via on-chart chips without leaving the chart workflow.
> **Owner:** @behnam-deriv
> **Result of manual execution (2026-08-03): this story does not appear to be implemented in this preview build.** Indicator management still goes entirely through the pre-existing production "Indicators" modal (Active/Momentum/Trend/Volatility/Moving averages/Others tabs, gear=edit, trash=delete). No on-chart chip exists anywhere on either viewport, and mobile doesn't even expose an entry point to Indicators at all (only "Chart types" and "Drawing tools" icons are present on the mobile toolbar). This lines up with the earlier finding that the Figma link shared for this plan only covers stories #5/#6, not #1 — get @behnam-deriv's actual design/build reference before re-testing this suite.

## Preconditions (all cases)

- On the trade page, any symbol/trade type selected
- Both viewports: Desktop ≥1280×800, Mobile 500×850

## Notes

1. **CHART-01/02 — desktop "maximize" is the browser's native Fullscreen API**, not an in-app layout change. Confirmed via `document.fullscreenElement` toggling `true`/`false` on click. The toggle itself works correctly both directions and doesn't break anything (verified trade-type switching and Buy both still work while "maximized"), but it diverges from the expected result as written and from mobile's behavior (mobile confirmed **not** to use native fullscreen — `fullscreenElement` stayed `false`, and mobile's button has a proper accessible name "Maximize chart"/"Minimize chart" vs desktop's unlabeled icon). Flag to @behnam-deriv: is desktop's native-fullscreen approach intentional, or should it match mobile's in-app expand?
2. **CHART-04 — the "add indicator" flow itself still works** (confirmed via the existing Active/Momentum/Trend/Volatility/Moving averages/Others categorized modal — added "Moving Average (MA)", it rendered on the chart, "Active" tab showed a count badge). What's **not** implemented is the story's actual ask: a chip on/near the chart for inline hide/edit/delete. Clicking directly on the rendered indicator line only triggers the chart's crosshair tooltip, not a chip. Edit is available via a gear icon in the modal's Active tab (opens a full "Moving Average (MA)" settings dialog — Color/Period/Field/Type/Offset/Reset/Done — stacked as a second modal, not inline). Delete is available via a trash icon in the same row (removes instantly, no confirmation). No hide/eye toggle exists anywhere.
3. Confirmed a real discrepancy relevant to **Suite 4** while testing CHART-03 on Accumulators: **desktop shows "Max. payout" as a separate row above the Buy button**, while **mobile combines it inside the Buy button** ("Buy / Max payout X USD") — carried this finding forward into `04-trade-parameter-interactions.md` (PARAM-ACC-04).
